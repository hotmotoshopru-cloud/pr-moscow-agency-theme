PRодвижение V12 — SEO и статьи

КУДА ПИСАТЬ НОВЫЕ СТАТЬИ
WordPress → Записи → Добавить запись.
Для каждой статьи: один конкретный поисковый интент, уникальный H1, рубрика, изображение записи, короткий анонс и 2–5 внутренних ссылок на услуги/другие статьи.
Главная автоматически показывает 6 последних опубликованных записей. Полный архив должен быть отдельной страницей «Блог / Статьи» (Настройки → Чтение → Страница записей).

КЛЮЧЕВЫЕ КЛАСТЕРЫ
Главная: PR агентство; PR агентство в Москве; пиар агентство Москва; PR компания Москва; PR услуги; PR продвижение; PR сопровождение; PR консалтинг.
Отдельные посадочные: продвижение в СМИ; связи со СМИ; медиапродвижение; управление репутацией / SERM; PR для бизнеса; PR бренда; персональный PR / PR эксперта; продвижение артистов; музыкальный PR; политический PR; антикризисный PR; SMM агентство; Telegram продвижение; VK продвижение; digital PR; организация мероприятий; брендинг; создание и SEO продвижение сайтов.
Не набивать все запросы на одну страницу: под крупные намерения нужны отдельные полезные посадочные страницы.

ТЕХНИЧЕСКОЕ SEO
Тема добавляет title главной, description, robots index/follow, canonical, Open Graph и JSON-LD Organization/ProfessionalService/WebSite/WebPage.
Современный WordPress имеет нативный XML sitemap: /wp-sitemap.xml.
После установки: проверить, что в Настройки → Чтение выключено «Попросить поисковые системы не индексировать сайт»; добавить сайт и sitemap в Яндекс Вебмастер и Google Search Console; привязать Яндекс Метрику; настроить HTTPS и единственную каноническую версию домена; проверить 404, мобильную версию, скорость и Core Web Vitals.
robots.txt.example — пример. Заменить YOUR-DOMAIN.RU на реальный домен перед использованием.

ВАЖНО
Не создавать десятки почти одинаковых SEO-страниц. У каждой посадочной должны быть собственная услуга/интент, кейсы, процесс, FAQ, цены/формат работы или другие реально полезные отличия.
